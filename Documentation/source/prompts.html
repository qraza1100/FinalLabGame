05
Building the complete game in Unity
22 Nov 2026 · Production
Prompt (as submitted)
complete the whole game in unity use any skill you want /skills
Formal statement of the request

Implement the full game in Unity from the agreed concept, using any available tools, and deliver a playable build.

AI response and actions
  • Environment: created a Unity 6.3 URP project using only packages already installed with the editor (no internet needed). Found that batch-mode builds need a signed-in Unity Hub.
  • 3D models: wrote a Blender Python script that models nine props (explorer sub, Heart of Eternity, sigil tablet, pearl, urchin, air vent, seaweed, coral, altar), exports them as FBX and saves SanctumProps.blend.
  • Level: designed a 27×21 ASCII maze, then checked by a breadth-first-search script that every sigil, the Heart and the escape route can be reached in order.
  • Gameplay code (C#): GameManager, GameSettings, SaveSystem, player movement and camera, pickups, gates, hazards, currents, shark AI, air vents, cracked walls, the escape sequence, HUD and menus.
  • Editor builder: scripts that generate the URP settings, materials, prefabs, both scenes, all UI and the Windows build from code.
  • 2D art: generated glyphs, UI sprites and effects with Python/Pillow; rendered the menu background and app icon from the mood-board art.
  • Testing: added an automated playtest mode that plays the whole game, logs results and captures screenshots. Fixed the problems found (menu background path, outline sprites, timer visibility, altar disappearing, layout overlaps, test data separation).
Result: Build/DrownedSanctum.exe (about 106 MB). Automated win and lose runs passed; 55–60 fps at 1920×1080 on the integrated GPU. README with an evaluation cheat-sheet.

08
Public repository and automatic build script
22 Nov 2026 · Release
Prompt (as submitted)
create a github repo with same name and public status and upload the whole code along build and add a script to build the project if code changes automated in the parent directory
Formal statement of the request

Create a public GitHub repository named FinalLabGame, upload the full project including the Windows build, and add a script at the project root that rebuilds the game automatically when the code changes.

AI response and actions
  • Wrote build.ps1 with build.bat and build-watch.bat wrappers.
    • It snapshots every source file and builds only when something has changed.
    • -Watch mode rebuilds a few seconds after a save.
    • Changes to the map or builder code also regenerate the scenes; other changes keep hand edits.
  • Tested one-shot, "no change" and watch modes. Found and fixed a ten-minute hang caused by waiting on Unity's licensing helper process.
  • Updated .gitignore so the build is included and added .gitattributes.
  • After the student signed in to GitHub in the assistant's browser, created the public repository and pushed 636 files.
Deliverables: github.com/qraza1100/FinalLabGame · build.ps1 · build.bat · build-watch.bat
